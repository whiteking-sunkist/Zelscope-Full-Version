## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Real-Time Signal Measurement** — Capture and visualize electrical signals as they fluctuate over time.
- **Dual Waveform Representation** — Analyze one or two simultaneous waveforms for comprehensive insights.
- **Bandwidth Range** — Operate within a frequency range of 10Hz to 20 KHz, suitable for human-audible signals.
- **Time Base Control** — Utilize a time base of up to 5 seconds for detailed waveform examination.
- **Export Options** — Export data in WAV, TXT, BMP, and EMF formats for further analysis and reporting.

### Advanced Features:

- **User-Friendly Interface** — Easy navigation and intuitive controls for seamless user experience.
- **High-Performance Sound Card Utilization** — Leverage your sound card as an oscilloscope input for enhanced performance.
